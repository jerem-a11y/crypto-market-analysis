# Cryptocurrency Market Behaviour and Risk Analysis (2021–2025)

## Project Overview

This project analyses the historical market behaviour and financial risk of three major cryptocurrencies: Bitcoin (BTC), Ethereum (ETH), and Solana (SOL).

The objective is to understand their price movements, returns, volatility, correlation, and risk-adjusted performance using Python.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Analysis Performed

1. Historical price analysis
2. Daily percentage returns
3. Volatility analysis
4. Cryptocurrency correlation
5. Moving averages (30-day and 90-day)
6. Market trend identification
7. Sharpe Ratio
8. Maximum Drawdown
9. Cumulative returns
10. Interactive dashboard development

## Key Findings

- Solana recorded the highest Sharpe Ratio (1.307).
- Bitcoin recorded the smallest Maximum Drawdown (-76.63%).
- Solana recorded the largest Maximum Drawdown (-96.27%).
- Bitcoin and Ethereum had the strongest positive return correlation (0.806).

## Conclusion

The analysis demonstrates that cryptocurrency assets have different risk and return characteristics. Solana showed stronger historical risk-adjusted performance but experienced greater downside risk, while Bitcoin demonstrated relatively better downside protection.

Historical performance does not guarantee future results.
