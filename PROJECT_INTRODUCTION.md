# Cryptocurrency Classification Using Machine Learning

## 1. Project Introduction

### Overview

This project focuses on applying Machine Learning classification techniques to cryptocurrency market data.

The goal is to develop classification models that can identify three different cryptocurrencies based on their market features:

- Bitcoin (BTC)
- Ethereum (ETH)
- Solana (SOL)

### Problem Statement

Cryptocurrency markets contain different characteristics that can be analysed using Data Science and Machine Learning techniques.

This project investigates whether selected market features can help distinguish between different cryptocurrencies.

### Project Objectives

1. Explore and understand cryptocurrency market data.
2. Perform data cleaning and preprocessing.
3. Conduct Exploratory Data Analysis (EDA).
4. Select relevant features for classification.
5. Train multiple Machine Learning classification algorithms.
6. Evaluate and compare model performance.
7. Identify the best-performing classification model.

### Project Scope

This project focuses on cryptocurrency classification, not cryptocurrency price prediction.
